# Jarvis v0.3.32 — language persistence and failure-path audit candidate

This is a review candidate. It does not establish complete translation of the interface and is not a published release.

- Serializes native language writes and prevents a delayed startup read from replacing a later user selection. Invalid local preferences no longer block valid native preferences. Storage failures are reported by the language picker.
- Updates the document language and reading direction, page headings, supported fuel/history/retail labels and date/number formatting when the selected language changes. Language selection does not convert stored currencies, translate personal content or rewrite data identifiers.
- Adds a desktop language picker and opens the mobile More-menu language list upwards so options can be reached within the viewport.
- Corrects word-count language detection and validates the detected language against the supported list. Legal requests use the selected language and clear their busy state after a provider failure.
- Validates fuel entries, prevents duplicate submissions, retains input after failed saves and requires storage acknowledgement before displaying a successful save/deletion.
- Tolerates corrupt or blocked optional tutorial preferences and adds the missing OBD2 vehicle-form cancel action.
- Updates four compatible development-tool dependencies. Production dependency audit reports zero known findings. Fifteen development-tool findings remain (five high, ten moderate); no forced major-version migration is included.

## Verification

- Runs the complete existing source test suite plus language race, storage failure, invalid input, provider detection, tutorial corruption and fuel-form rejection regressions.
- Requires source parsing, lint, the existing limited TypeScript check, signed-core-rule verification and production dependency audit.
- Checks all 33 routes and 42 language choices in the installed Windows app, including native/local persistence, document language/direction and reload. Pointer hit testing and actual mouse events detect covered or unreachable controls.
- Adds passive checks for finance/retail/holding tabs, business-detail tabs/forms, invoice/contact/device/routine/vehicle forms and five image-editor drawers in all five existing UI catalogs; also checks desktop language controls and uncaught renderer exceptions.
- Preserves the Windows packaging, native toolchain/admin, startup, real NSIS install, financial transaction, Gmail configuration, restart and uninstall gates.

Only Hungarian, English, German, French and Spanish UI catalogs exist. The other 37 selectable languages use English fallback; German/French/Spanish still miss existing keys. Hardcoded labels, tutorials and legal/privacy pages remain partially untranslated even in Hungarian/English. A green workflow verifies the tested technical behavior, not complete translations or the absence of every bug. Live AI, Google consent/email delivery, microphone/audio and physical-device acceptance remain separate.
