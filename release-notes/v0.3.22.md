# Jarvis v0.3.22

Stability update for the Windows desktop application.

- Preserve pending offline route actions without silently trimming the queue; retry conversation snapshots while the network remains online.
- Settle cancelled speech playback, reject stale microphone acquisitions and isolate callbacks from older capture sessions. Cache synthesized speech by model, voice, gender, language and exact text.
- Validate private-device addresses as IP literals, support bracketed IPv6 and reject lookalike public domains and embedded credentials.
- Read the memory extractor's actual gateway response and respect the learning-memory preference.
- Generate diagnostic PDFs locally with pagination and an embedded Hungarian font; enable conversation export and setup reopening.
- Preserve legitimate JSON, code examples and user messages while filtering internal action payloads.
- Search before applying result limits; validate comma decimals and reject malformed or nonfinite numbers.
- Check reminder date and time periodically while Jarvis is running; already displayed reminders no longer block unseen reminders.
- Reject unsupported physical-device commands and report failed scene/routine steps accurately.
- Restore the previous renderer and runtime activation after failed Self-Repair, retain the packaged toolchain and installed-source fingerprint across successive repairs, and preserve the installed Jarvis executable for update restarts.
- Include version-specific release notes in packaged Self-Repair workspaces.

## Verification

The extracted 0.3.21 source with these fixes passed 252 automated tests, lint, typecheck, policy verification and renderer build on Linux. The 0.3.22 commit requires its own Windows CI build, packaged toolchain checks and startup smoke test before release. Actual microphone, provider, OBD and repeated Self-Repair behavior still require manual acceptance testing.

Reminders require the application to remain running. This update does not add an operating-system background reminder service. Unsigned installers do not establish trusted publisher identity.
