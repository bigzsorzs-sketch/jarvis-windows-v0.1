# Privacy Policy – Jarvis Assistant

Jarvis Assistant processes personal data to provide voice assistance, health logging, reminders, finance tracking, smart home control, diagnostics, navigation history, and optional third-party integrations.

## Data categories
- Account data: name, email, profile settings
- Health data: blood sugar, meals, medications, sensor readings
- Financial data: invoices, finance entries, business records
- Contacts data: names, phone numbers, email addresses, relationship details
- Location data: saved locations, route history, navigation sessions
- Audio / microphone data: live voice input for speech recognition and assistant actions
- Device / sensor data: Bluetooth, OBD2, vehicle diagnostics, glucose sensors, smart device states
- Integration data: Gmail, Calendar, and other connected account data when enabled by the user
- AI processing data: user prompts, attached files, and structured context needed to fulfill requests

## How data is used
- To operate app features requested by the user
- To sync personal records across devices
- To generate AI responses and automations
- To provide reminders, reports, diagnostics, and exports
- To maintain security, logging, and abuse prevention

## Third-party processing
Some data may be processed by third-party services strictly for feature delivery, including:
- AI inference providers
- Email/calendar providers connected by the user
- Platform infrastructure and file storage services

## Data sharing
User data is not sold. Data is shared only:
- with service providers required to run requested features
- when the user explicitly connects an external service
- when required by law

## Retention
Data is retained until the user deletes it, exports it, or deletes the account, unless longer retention is required for legal or security reasons.

## Account deletion and export
The app supports account deletion and data export. When the user requests deletion, account-linked personal data is removed according to platform and legal limits.

## Security
Reasonable technical and organizational measures are used to protect data, including authenticated access controls and scoped storage.

## User controls
Users can review, update, export, and delete supported records within the app.

## Contact
The app publisher is responsible for providing the final public contact email/address shown in the store listing and privacy page.
